### 2. 看清 CPU、内存和磁盘组合

小型静态网站、测试环境和低负载服务，资源需求与数据库、多个容器或繁忙应用不同。内存不足时，系统可能频繁使用交换空间，响应时间会受影响；CPU 核数较多，也不代表单核性能或持续负载表现必然更好。

端口速率表示链路能力上限，月流量则是可传输的数据配额。官网新加坡套餐的月流量从 500 GB 到 8 TB，端口速率从 1.5 Gbps 到 5 Gbps。高速端口并不意味着每月流量无限，也不表示服务器会持续以端口上限传输。
